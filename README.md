# LockCall · Site

Versão web do LockCall para publicar no GitHub Pages, sem extensão.

## Atualizar o site
1. Extraia o ZIP.
2. Envie `index.html`, `.nojekyll`, `robots.txt` e `sitemap.xml` para a raiz do repositório `Gueten/lock-site`.
3. Mantenha o GitHub Pages em `main` / `/(root)`.

## Recursos
- Perfil com nome e foto, incluindo GIF animado leve.
- Chat com avatar, menções, respostas e emojis; links diretos de GIF aparecem inline sem botão especial.
- Todos os participantes podem ligar/desligar o próprio microfone, câmera ou compartilhamento de tela, sujeito às permissões do navegador.
- Até três transmissões simultâneas por sala, incluindo câmera compartilhada.
- Configurações locais de resolução, qualidade de microfone, redução de ruído, eco, volume recebido e tema.

As chamadas usam PeerJS/WebRTC. Rede, firewall, permissões do navegador e recursos do dispositivo podem afetar mídia em tempo real.
