# LockCall 2.5

Atualização do site estático para GitHub Pages.

## Mudanças nesta versão
- Painel de amigos movido para o canto esquerdo da página inicial (desktop e celular).
- Botão de adicionar amigo em formato de pequena bolha no canto de cada plaqueta de participante.
- Convites de sala exibidos em aviso flutuante no canto inferior. Ao aceitar, o convidado entra diretamente na sala, sem gerar uma segunda solicitação de aprovação.
- Pedidos para entrar continuam exibidos em aviso flutuante para o anfitrião, com aceitar/recusar.
- Avisos de convite enviado, pedido enviado e convite aceito também aparecem como bolhas temporárias.

## Publicação
Substitua os arquivos da raiz do repositório `Gueten/lock-site` pelo conteúdo desta pasta e aguarde a publicação do GitHub Pages.

## Limitação conhecida
O sistema de amigos da versão estática usa PeerJS e armazenamento local do navegador. Não há sincronização de conta persistente entre dispositivos.
